<h1>Kevin's Quest</h1>

Kevin's Quest was created within a group project for my graded unit in college, which resulted in me obtaining an A. This game features 2 levels and unique enemies per level, Level One designed by my teammate whilst I designed the other. We worked together to create this game in a small duo.

- Classic platformer controls
- Unique Artstyle
- Highscore Saving
- Unique enemies
- Time Trial
